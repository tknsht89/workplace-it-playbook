# Workplace IT Playbook

Practical playbooks, checklists, and troubleshooting notes for workplace IT operations.

## Purpose

This repository documents repeatable, practical approaches for supporting workplace IT environments.

The goal is to make common operational tasks easier to understand, troubleshoot, and maintain.

## Topics

- Office networks and Wi-Fi
- Online meeting quality and first-line troubleshooting
- Printers, phones, and shared workplace devices
- IT migration preparation and vendor coordination
- Operational checklists and documentation practices

## How to Use This Repository

Each note is designed to help identify a problem, perform first-line checks, interpret results, and decide on a next action.

## Publishing Rules

All examples are fictional, anonymized, sanitized, or use modified values.

I do not publish:

- Customer or company names
- IP addresses, SSIDs, credentials, or internal network details
- Internal screenshots, confidential documents, quotations, or contract information
- Personally identifiable information
- Unreported vulnerabilities or instructions for targeting real systems

## Repository Structure

```text

└─ YYYY-MM-DD-topic-name.md
```
